StoryLark · open gallery

Themes & presentation templates

StoryLark separates how a site looks (a theme: colors, fonts, highlight glow) from how it's structured (a presentation template: screens, layout, navigation). Browse both here, use any of them freely, and submit your own.

Themes

A theme is a brand.json + theme.css token pair — swap it without touching code.

Presentation templates

A template defines the screens and flow a library is presented with.

Submit yours

Built a theme or a template? Open a pull request against the gallery repo adding your entry to registry.json with a link to your source. Themes need the token contract (docs); templates need the screen contract. That's it — once merged, it appears here.
