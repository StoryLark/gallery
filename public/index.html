StoryLark · open gallery

Make a StoryLark yours

StoryLark is an open-source, self-hostable read-along storybook engine: word-synced narration, offline reading, install-to-home-screen. Every deployment customizes it on two independent surfaces, and this gallery collects both:

Themes control how a site looks — a brand.json + theme.css token pair covering colors, fonts, the read-along highlight glow, icons, and dark mode. Swapping a theme never touches code.

Presentation templates control how a library is structured — the screens, layout, and navigation a reader moves through. The same stories can be presented as a flat library, a series shelf, or anything the contract allows.

Everything here is free to use in your own deployment. Mix any theme with any template.

Built a theme or a template? Open a pull request against the gallery repo adding your entry to registry.json with a link to your source. Themes need the token contract (docs); templates need the screen contract. Once merged, it appears here.
