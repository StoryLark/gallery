StoryLark · open gallery

Make a StoryLark yours

StoryLark is an open-source, self-hostable read-along storybook engine: word-synced narration, offline reading, install-to-home-screen. Every deployment customizes it on two independent surfaces, and this gallery collects both:

Themes control how a site looks — a brand.json + theme.css token pair covering colors, fonts, the read-along highlight glow, icons, and dark mode. A theme installs as a package on a live deployment (admin portal or CLI) — no rebuild, no code touched.

Presentation examples show how a library can be structured — the screens, layout, and navigation a reader moves through, via presentation.json. The same stories can be presented as a flat library, a series shelf, or anything the contract allows. This isn't a separately installable package yet: a presentation shape ships bundled inside a theme package, or is copied by hand.

Everything here is free to use in your own deployment. Mix any theme with any presentation shape.

Submit yours

Built a theme or a presentation example? Fork the gallery repo, add one entry to registry.json, and open a pull request. Every submission is reviewed before it lands — the full process and review criteria are in CONTRIBUTING. Once merged, it appears here automatically.
