Presentation Examples

presentation.json defines the screens, nav, and flow a story library is presented with — independent of any theme. The same stories can be a flat library, a series shelf, or whatever the contract allows. This isn't yet its own installable package — today a shape ships bundled inside a theme's package as an optional file, or you copy it into presentation/<your-id>/ by hand. A standalone, importable storylark-template-* format is planned but not built.
